# 镜像抽出卡片 · Mirrored Card Stack

[English](README.md) · **简体中文**

当前顶卡向两侧镜像抽出，换层后回插，保留惯性和中途接住的姿态。

[在线调整此动效](https://tuneshape.kai-nex.com/#/effect/mirrored-card-stack) · [动效说明与默认参数](https://tuneshape.kai-nex.com/effects/mirrored-card-stack/) · [全部开源动效](../../README.zh-CN.md)

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/mirrored-card-stack/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 起点与终点

共 6 张灰阶编号卡片：1 / 2 / 3 / 4 / 5 / 6；初始显示「1」。背景 #f1f1f1、白字和直角；没有作品照片、项目标题、私有字体或案例链接。

## 触发方式

左右拖动、左右键、箭头和分页点切换。两侧都抽出当前顶卡，再换层回插；上一张和下一张始终保留明确方向。仅有两张时也不以按 ID 选择代替方向命令。

## 时序

相邻按键切换基准 980 ms；原始基准为 980 ms，远跳的原始计划每多跨一张增加 160 ms（最多增加四次），再按同一时钟倍率缩放。按键使用五次轨迹，拖动释放使用原解析弹簧。观察倍速只改变原控制器的时间步长，不增加第二个 RAF，不写入配置。

## 外观

基准卡片 280 × 350px，编号基准字号 36px，整体等比适配画布。抽离峰点为 .90 倍卡宽、12°、.84 比例，在 .58 附近换层。保留 C2 路径连接、轻透视、固定光向与层间遮蔽；卡片宿主保持 overflow:visible。

## 进入与退出

卡片从当前可见姿态短抽离，经过峰点后进入最近的接收层，再平滑归位。两边都移动原来的顶卡；此条目保存用户指定的镜像模式，不切换为堆底卡倒放返回。

## 重复操作与打断

短甩保留输入速度和惯性回弹；按键重定向接续当前位置与同向速度。中途按住保留完整已绘制姿态，轻微反向移动可继续。暂停、禁用、离屏与后台取消旧指针和轨迹并落位，恢复不启动旧工作。

## 减少动态效果

减少动态效果时程序切换直接到位，目录不自动演示；直接拖动仍跟随手势。区域可聚焦并使用左右键，按钮和分页点有独立名称；卡片不绑定任何案例跳转。

## 导出与接入

1–8 张卡片的编号、灰度、初始项、基准尺寸、字号和时长共用一份配置。灰卡由本地 SVG 生成，预览、JSON、Motion、离线 HTML 与复刻工程使用同一控制器、路径、材料及 Swiper 依赖。选择、速度、焦点和手势不保存。保留可见 Skiper UI 署名和全部许可；不额外提供图片或视频导出。
