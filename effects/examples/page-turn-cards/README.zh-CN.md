# 翻页卡片 · Page Turn Cards

[English](README.md) · **简体中文**

两张独立刚性卡片沿各自边轴翻转，以连续窄缝和柔光完成交接。

[在线调整此动效](https://tuneshape.kai-nex.com/#/effect/page-turn-cards) · [动效说明与默认参数](https://tuneshape.kai-nex.com/effects/page-turn-cards/) · [全部开源动效](../../README.zh-CN.md)

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/page-turn-cards/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 起点与终点

共 6 张灰阶卡片：1 / 2 / 3 / 4 / 5 / 6；初始显示「1」。背景固定 #f1f1f1，文字为白色，卡片保持直角。

## 触发方式

左右拖动、方向键、左右按钮和分页点切换。目录悬停、键盘聚焦或手机 Preview 演示一页；手动操作后停止演示重播，重新进入再恢复。点击控件不打开详情。

## 时序

基准完整翻页 600 ms，cubic-bezier(.42,0,.58,1) 缓入缓出；拖动后的落位按剩余距离缩短。观察倍速只改变运行时，不写入配置。没有额外自动轮播时钟。

## 外观

卡片基准 280 × 336px，编号 48px；整体等比适配画布。透视 2.8 倍卡宽、最大转角 100°，退后 0.10 倍卡宽。两侧光衰减 .18、方向差 .018。投影窄缝 3–6px，随进度出现和收回；卡片独立，表面不粘连。

## 重复操作与打断

相邻翻页可重新抓取；远跳仅显示起止两张卡片，短时禁止重新抓取。连续选择保留最后意图。暂停、禁用、离屏、后台和重建时落稳并取消旧队列，恢复不会重放已取消请求。

## 减少动态效果

减少动态效果时不自动演示，程序选择直接到位；手动拖动仍跟随手势。区域可 Tab 聚焦并使用左右键；分页点和按钮有独立名称及可见焦点。

## 导出与接入

卡片支持 1–8 项，灰度、文字、基准尺寸、字号、初始项与时长均来自同一配置。说明、JSON、Motion、预览、离线 HTML 和复刻工程共用渲染器、CSS 和 vendored Swiper。选择与队列不保存；不包含图片、作品文案、私有字体或原站接口。此条目不额外提供图片或视频导出。

## 进入与退出

去向卡片先转出，来向卡片略错时转入；每张卡片以自己的边轴运动，结束后只保留选中卡片。没有共享折痕或途经卡片闪现。
