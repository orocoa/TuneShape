# 弹性拖动视频播放器 · Elastic Video Player

[English](README.md) · **简体中文**

竖屏视频配合可拉伸进度条、悬停时间标记与播放反馈。

[在线调整此动效](https://tuneshape.kai-nex.com/#/effect/skiper-91) · [动效说明与默认参数](https://tuneshape.kai-nex.com/effects/skiper-91/) · [全部开源动效](../../README.zh-CN.md)

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/skiper-91/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 触发方式

点击视频播放或暂停；拖动进度条定位，方向键每次移动 5 秒，Home/End 到首尾。更换视频和封面，调节画面高度、圆角、进度条厚度与拉伸幅度；响应基准调节界面回弹，不改变视频长度。音量范围 0–1，视频时长读取当前媒体。目录悬停、聚焦和手机 Preview 共用演示，标题进入编辑器。

## 参数与内容

视频地址 / data URI: "/video/skiper-91.mp4"；封面地址（可留空）: ""；视频高度: 500；视频圆角: 32；容器圆角: 50；进度区宽度: 400；进度条厚度: 6；边缘拉伸幅度: 24；画布背景: "#f1f1f1"；容器颜色: "#f1f1f1"；轨道底色: "#f5f5f5"；已播放颜色: "#404040"；悬停标记颜色: "#f97316"；显示播放时间: true；默认静音: true；音量: 0.8；视频循环: false

## 起点与终点

初始画面使用以上保存内容。逻辑画布 768 × 720，整体缩放 1，位置偏移 (0, 0)。

## 时序

响应基准 500 ms，演示延迟 0 ms。观察倍速仅用于预览。

## 进入与退出

竖屏视频配合可拉伸进度条、悬停时间标记与播放反馈。 演示停止后保留组件的当前交互状态。

## 重复操作与打断

离开目录且失焦、滚出可视区和切换后台会停止演示。实际输入、当前选择与播放进度不覆盖保存的默认值。

## 参数与导出

控件、预览、JSON、Motion 适配器、复刻工程和 HTML 导出共用同一设置对象与渲染器。目录卡片始终显示项目默认预设。

## 减少动态效果

不自动演示，过渡直接呈现目标状态；保留真实输入、按钮、选择和键盘操作。
