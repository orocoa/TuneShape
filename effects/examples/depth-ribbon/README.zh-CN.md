# 纵深图带 · Depth Ribbon

[English](README.md) · **简体中文**

图片沿三维曲线串成图带，镜头在全貌与穿行之间切换。

[在线调整此动效](https://tuneshape.kai-nex.com/#/effect/depth-ribbon) · [动效说明与默认参数](https://tuneshape.kai-nex.com/effects/depth-ribbon/) · [全部开源动效](../../README.zh-CN.md)

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/depth-ribbon/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 内容与参数

8 张 TuneShape 原创抽象图像；PNG、JPEG、WebP 本地处理，可编辑标题与副标题。每轮独立洗牌并重复铺满 72 张卡片，排布种子 0。图片与参数嵌入 JSON 和离线导出。

## 路径与外观

路径 loop；镜头 cycle。三种闭合路径按弧长等距排布。卡片尺寸 0.72、宽高比 1、圆角 0.12；镜头偏移 1、视野 60°、雾化 1。轨迹线 #b19eef / 0.3，阴影 0.5，背景 #f1f1f1。

## 起点与终点

初态从俯瞰全貌进入；循环镜头依次俯瞰、下潜、穿行和拉远。持续穿行模式沿图带循环，全貌模式缓慢绕行。目录静止时保持可读全貌。

## 时序

穿行速度 0.6 张/秒；负数倒行，0 停止前进。循环中穿行 9 秒，俯瞰约 1.8 秒，进出各约 1.5 秒。自动穿行开启；工具栏暂停冻结全部运行时，继续保留位置。

## 进入与退出

点击图片或 Enter 将镜头拉近，按原始比例完整显示。近看高度最多为画面的 66%，并根据标题、控件和屏幕比例调整距离。再次点按或 Escape 返回当前所选卡片的位置继续穿行；滚轮先退出近看。

## 触发方式

交互开启；鼠标纵向拖拽、触屏横向拖拽与滚轮穿行。触屏纵向滚动仍交给页面。按住画面或空格查看全貌，按住拖动可旋转全貌，松开回到穿行。手动穿行接管当前镜头；重新演示恢复所选镜头模式。

## 图片切换

近看时用上一张 / 下一张按钮、方向键或触屏横向轻扫沿图带顺序循环。切换与中途返回都从当前镜头接续；标题关闭时仍保留导航；窄卡片显示序号，完整标题保留在可访问名称和悬停提示中。按钮上的 Escape 关闭图片并把键盘焦点还给图库。连续浏览按钮和轻扫是 TuneShape 的增强，选择、切换进度与焦距不写入配置。

## 重复操作与打断

目录只在悬停、聚焦或手机 Preview 时自动演示；离开且失焦、离屏或后台停止，再次进入可重播。悬停图片可暂停穿行。图片选择、镜头、当前位置和惯性只属于运行时，不写入配置或导出。

## 减少动态效果

保持静止全貌，不自动穿行、循环或产生惯性。手动拖拽、滚轮与方向键直接定位；图片立即拉近和返回，空格仍能查看全貌。
