# ASCII 鲨鱼群 · ASCII Sharks

[English](README.md) · **简体中文**

俯视游动的鲨鱼与小鱼，以可调密度的字符网格构成动态背景。

[在线调整此动效](https://tuneshape.kai-nex.com/#/effect/ascii-sharks) · [动效说明与默认参数](https://tuneshape.kai-nex.com/effects/ascii-sharks/) · [全部开源动效](../../README.zh-CN.md)

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/ascii-sharks/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 触发方式

目录卡片悬停、聚焦或手机预览时播放；详情自动运行，播放按钮可暂停并接续。

## 起点与终点

画面铺满宿主，字符采样密度 2×，字符尺寸 0.9×；鲨鱼 4 条，大小 1×，鱼群密度 1×。

## 时序

单次播放时长 12000 ms，触发延迟 0 ms；游动速度 1.7×；持续循环。速度为 0 和暂停均保持当前画面；观察倍速只影响运行时。

## 进入与退出

离开且失焦、滚出可视区或切换后台时停止演示；再次进入可重新播放。背景不反向倒放。

## 字符密度

稀疏 0.6×、均衡 1×、细密 1.6×、高密度 2×，并可在 0.5–2× 连续调节；密度控制采样网格，字符尺寸控制网格中的字形大小。当前背景网格强度 0.04，尾迹强度 0。

## 重复操作与打断

外观设置来自同一份配置；鱼群位置、累计时钟和目录运行状态不写入 JSON。播放接续暂停位置，重新演示从初态开始。

## 游动方式

20 节脊柱逐节跟随头部走过的路径，关节限制弯折幅度；摆尾波叠加在连续脊柱上，频率跟随前进速度，胸鳍随转弯轻微收展。鱼群传递警戒，向鲨鱼两侧散开，危险消退后重新聚拢。

## 减少动态效果

遵循系统设置，只呈现静态画面，不自动循环。

## 配色与自主游动

背景 #eeeeee；字符 #303030；字符不透明度 0.9；鼠标扰动开启：靠近时鱼会加速并转弯避开，小鱼响应更快，鲨鱼保留惯性；移开后逐渐降速，不吸回原位。

## 交互方式

移动鼠标时附近生物平滑避让；点击或轻触水面产生局部涟漪和惊散，鲨鱼保留转弯惯性。触屏滑动不跟随手指，也不拦截页面滚动。关闭交互、暂停或减少动态效果时不接受新扰动。
