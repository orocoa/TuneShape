## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/text-rise/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 触发方式

点击组件、播放按钮或按 Enter / 空格，从遮罩下方逐字向上揭示；随后在原位淡出，完全不可见后才复位并开始下一轮。文字不会向下退回；工具栏可暂停和继续。 详情页播放按钮演示逐字上移揭示、原位淡出、不可见时复位；开启循环后从头继续，暂停与继续保留当前阶段进度。

## 起点与终点

字符 1的纵向位移：105% → 0%；字符 2的纵向位移：105% → 0%；字符 3的纵向位移：105% → 0%；字符 4的纵向位移：105% → 0%；字符 5的纵向位移：105% → 0%；字符 6的纵向位移：105% → 0%；字符 7的纵向位移：105% → 0%；字符 8的纵向位移：105% → 0%；字符 9的纵向位移：105% → 0%；整体的横向位移：0 → 0；整体的纵向位移：0 → 0；整体的缩放：1 → 1；整体的不透明度：1 → 1。

## 时序

揭示阶段 1160 ms，触发延迟 0 ms，三次贝塞尔曲线 cubic-bezier(0.22, 1, 0.36, 1)。随后原位淡出 406 ms，使用柔和缓入缓出；一轮共 1566 ms。

## 进入与退出

文字按错峰时序从下向上揭示。全部到位后保持位置不动，以揭示时长的 35% 平滑淡出至不透明度 0；完全不可见后才在遮罩下方复位，不反向下移。淡出后重新逐字上移揭示，按整轮持续循环。

## 重复操作与打断

一次新演示先在不可见时复位，再逐字向上揭示；淡出阶段只改变不透明度。暂停保留字符位置、透明度与阶段进度，继续时接续，不排队。

## 减少动态效果

遵循系统 prefers-reduced-motion，跳过延迟、循环和动画，直接呈现目标帧。观察倍速只修改 Motion 控制器 speed，不写入配置。
