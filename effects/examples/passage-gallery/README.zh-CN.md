# 穿行图库 · Passage Gallery

[English](README.md) · **简体中文**

沿铺满图片的隧道穿行，视角跟随指针，图片从墙面展开。

[在线调整此动效](https://tuneshape.kai-nex.com/#/effect/passage-gallery) · [动效说明与默认参数](https://tuneshape.kai-nex.com/effects/passage-gallery/) · [全部开源动效](../../README.zh-CN.md)

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/passage-gallery/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 内容与参数

8 张 TuneShape 原创抽象图像；支持 PNG、JPEG、WebP 本地处理和标题编辑。自定义图片嵌入 JSON 与离线导出，不依赖远程图片服务。

## 布局

横向 5 格；墙面格数按场景比例计算。间隙 0.1，圆角 0.06，图片占比 0.3，强调色占比 0.06，网格线 0.12。种子 0 决定稳定排布。

## 外观

强调色 #5227ff → #ff9ffc，背景 #fafafa；雾化 1，垂直视野 72°，视线跟随 1，悬停高亮 1。独立 Canvas 透视细分与高速拖影，材质和运动模糊不等同原 Pro 着色器。

## 起点与终点

初态是由固定种子生成的四面图片隧道；穿行不断循环生成前方格子。打开图片后保持在中央，收回后继续穿行。

## 时序

巡航速度 0.6 格/秒；负数后退，0 静止。按住加速 10 倍，高速拖影 1。自动巡航开启；速度和交互独立计时，工具栏暂停冻结全部运行时，继续接续位置。

## 进入与退出

点击图片从墙面平滑飞到中央，近看高度最多为画面的 66%，按原始比例完整展示，并为标题与按钮留出空间。再次点按或 Escape 收回到当前图片对应的墙面；滚轮先关闭图片再穿行。

## 触发方式

交互开启。鼠标纵向拖动、触屏横向拖动，纵向触屏滚动仍由页面处理；方向键穿行，Home 复位。滚轮穿行开启。点击 / Enter 展开图片，再次点按或 Escape 收回；图片标题显示。

## 图片切换

近看时用上一张 / 下一张按钮、方向键或触屏横向轻扫连续浏览，按图片内容顺序循环。关闭标题仍保留切换与关闭按钮；窄卡片显示序号，完整标题保留在可访问名称和悬停提示中。快速切换从当前画面接续并交叉淡化，退出回到新选图片对应的墙面；按钮上的 Escape 也能关闭并把键盘焦点还给图库。这些连续浏览入口是 TuneShape 对公开演示的增强。

## 重复操作与打断

目录仅在悬停、聚焦或手机 Preview 期间巡航，离开且失焦、离屏或后台停止。聚焦图片暂停巡航；收回后继续。焦点、当前位置、指针、加速和拖影都不写入配置或导出。

## 减少动态效果

不自动巡航、不加速、不产生惯性或拖影；手动拖动、滚轮与方向键直接定位，图片立即展开和收回。
