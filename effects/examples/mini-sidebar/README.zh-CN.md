页面导航 · 400 ms · Ariadne

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/mini-sidebar/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 触发方式

内容与动效库的用途分类同步，所有分类处于同一层。进入导航区域查看名称，点击直接选中分类，再次点击保持选择。支持触屏点按；方向键和 Home/End 在同一层移动焦点。移开、离焦或 Escape 后平滑收回横线并隐藏文字，保留当前选择。 详情页播放按钮同步演示两侧：普通动效从初态进入终态，再返回初态一次；加载类按循环配置持续播放。暂停保留当前画面，继续时从暂停进度接续。

## 起点与终点

单层用途分类；横线从收拢态平滑伸出，最大长度 38 px。整体缩放 100%，在初态和展开时一致；横线、间距和标签同步缩放。

## 时序

演示与收回时长 400 ms，触发延迟 0 ms，三次贝塞尔曲线 cubic-bezier(0.4, 0, 0.2, 1)。悬停伸展使用固定响应的解析临界阻尼弹簧；时长与曲线用于演示轨道和移开收回。

## 进入与退出

初态显示各用途分类的短线。进入导航区域后，附近横线按距离伸长并显示名称；点击直接选中分类。移开时平滑收回横线并淡出名称，保留当前选择。完成后保留终态，不自动重复。

## 重复操作与打断

指针位置、焦点和当前项为临时交互状态，不写入配置。点击直接切换分类；方向键和 Home/End 在同一层移动焦点。横线使用持续时钟跟随指针，换方向时保留当前速度。移开、焦点移出或按 Escape 后保留当前项，标签在原来的位置淡出，横线从当前长度平滑收回；退出始终接续当前画面，不排队。

## 减少动态效果

遵循系统 prefers-reduced-motion，跳过延迟、循环和动画，直接呈现目标帧。观察倍速只修改 Motion 控制器 speed，不写入配置。
