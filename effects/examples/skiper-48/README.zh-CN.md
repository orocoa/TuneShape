# 卡片堆叠滑动轮播 · Card Swipe Carousel

[English](README.md) · **简体中文**

拖拽站内几何图片卡片，后方卡片以旋转和纵深堆叠，松手吸附到上一张或下一张。

[在线调整此动效](https://tuneshape.kai-nex.com/#/effect/skiper-48) · [动效说明与默认参数](https://tuneshape.kai-nex.com/effects/skiper-48/) · [全部开源动效](../../README.zh-CN.md)

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/skiper-48/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 触发方式

默认复用站内六张原创黑白几何图。左右拖动或用方向键切换卡片，Home/End 到首尾。图片每行一张；宽高改变卡片，侧移按百分比、旋转按角度、纵深按像素调节。默认图片序号从 0 开始；自动轮播间隔使用毫秒。目录悬停、聚焦和手机 Preview 共用演示，标题进入编辑器。

## 时序

响应基准 300 ms，演示延迟 0 ms。观察倍速仅用于预览。

## 进入与退出

拖拽站内几何图片卡片，后方卡片以旋转和纵深堆叠，松手吸附到上一张或下一张。 演示停止后保留组件的当前交互状态。

## 重复操作与打断

离开目录且失焦、滚出可视区和切换后台会停止演示。实际输入、当前选择与播放进度不覆盖保存的默认值。

## 参数与导出

控件、预览、JSON、Motion 适配器、复刻工程和 HTML 导出共用同一设置对象与渲染器。目录卡片始终显示项目默认预设。

## 减少动态效果

不自动演示，过渡直接呈现目标状态；保留真实输入、按钮、选择和键盘操作。
