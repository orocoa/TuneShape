# 三点交错跳动 · Staggered Loading Dots

[English](README.md) · **简体中文**

三点交错跳动 · 1200 ms · Ariadne

[在线调整此动效](https://tuneshape.kai-nex.com/#/effect/dots) · [全部开源动效](../../README.zh-CN.md)

## 本地运行

从仓库根目录执行。各示例使用公开的共享渲染源码，完整网页编辑器不是运行依赖。

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev --open /examples/dots/
```

使用 `config.json` 调整配置；点击 Play / Pause / Replay 验证播放与打断。构建全部示例：`pnpm build`。

## 触发方式

列表中指针进入预览区域后播放，按配置的循环选项重复，离开即停止；详情中自动播放加载效果；播放期间按钮显示暂停，暂停后保留当前画面，再次播放从暂停处继续。 详情页自动按配置播放完整周期；暂停保持当前画面，继续从同一进度接续，不反向返回。

## 起点与终点

圆点 1的纵向位移：0 → 0（含 4 个关键帧）；圆点 1的不透明度：0.4 → 0.4（含 4 个关键帧）；圆点 2的纵向位移：0 → 0（含 4 个关键帧）；圆点 2的不透明度：0.4 → 0.4（含 4 个关键帧）；圆点 3的纵向位移：0 → 0（含 4 个关键帧）；圆点 3的不透明度：0.4 → 0.4（含 4 个关键帧）；整体的横向位移：0 → 0；整体的纵向位移：0 → 0；整体的缩放：1 → 1。

## 时序

总时长 1200 ms，统一触发延迟 0 ms，三次贝塞尔曲线 cubic-bezier(0.42, 0, 0.58, 1)。各轨道按配置中的 start / span 和 times 分阶段运行。

## 进入与退出

按关键帧正向运行完整周期；暂停保持当前画面，继续接续，不执行反向退出。按完整正向周期无限循环；工具栏暂停不改变循环设置。

## 重复操作与打断

暂停保持当前周期进度，继续接续；修改参数时按新配置从完整周期起点重播，不排队。

## 减少动态效果

遵循系统 prefers-reduced-motion，跳过延迟、循环和动画，直接呈现目标帧。观察倍速只修改 Motion 控制器 speed，不写入配置。
