## Updated behavior

- Eye Tracker runs a visible gaze tour during an explicit demo, yields to real pointer input, and reports actual motion rather than its idle frame clock.
- Depth Ribbon defaults to the shared `#f1f1f1` gray surface.
- The Skiper gallery includes the endless-canvas mode, scroll/stack scenes and current motion settings.
- Public renderers include current native pointer, keyboard and reduced-motion behavior. Upload Dropzone, Slide to Confirm and Wake Slider require real input; use their native controls directly.
- Original gallery artwork, provenance and matching image bytes are included so renderer tests run from a clean checkout. Generic public demonstration media and existing licenses are retained.
- README tables, the machine-readable catalog and repository metadata agree on 73 effects.

## Run locally

```sh
cd effects
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```

Edit an example's `config.json`, then open `/examples/<effect-id>/` in the local server. Keep source notices and font licenses when reusing the code.

This is a GitHub source release. The complete website editor and deployment infrastructure remain separate; this release does not deploy the website. The latest catalog-layout experiment remains a local preview.
