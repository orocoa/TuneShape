# Finding and citing TuneShape effects

Every current effect has a stable ID, bilingual README, exact default configuration, source entry, and link to the online editor. Start at [the effects index](../effects/README.md) or its [Chinese version](../effects/README.zh-CN.md).

The [catalog](../effects/catalog.json) provides names, summaries, categories, configuration paths, source URLs and editor URLs as JSON. [llms.txt](../llms.txt) is a plain-text source index; [codemeta.json](../codemeta.json) describes the software and its parts; [CITATION.cff](../CITATION.cff) provides citation metadata. Their statements come from the maintained configuration and descriptions, not generated usage or ranking claims.

All documentation is committed as ordinary readable files. Third-party attributions and font licenses travel with the source. Reusing an effect should preserve its source notice and include a repository URL plus the commit used. These files make discovery and citation easier; they do not establish search indexing, ranking, or AI citation outcomes.

## 中文

每个当前动效都有固定 ID、双语说明、默认配置、源码入口和网页编辑器链接。机器可读清单与引用信息用于准确识别项目及动效；它们不代表已经取得搜索收录、排名或 AI 引用。复用时请保留署名和许可，并记录仓库链接与所用提交。
